Projeto SPODWE2 – Website
O projeto deve ser desenvolvido em grupos de três alunos. Para cada grupo será sorteado um dos
temas abaixo:
1. Agendamento Médico
Exemplos de entidades: Consulta, Especialidade, Médico, Paciente.
2. Cursos Online
Exemplos de entidades: Curso, Categoria, Instrutor, Aluno.
3. Locação de Imóveis
Exemplos de entidades: Imobiliária, Imóvel, Corretor, Proposta.
Requisitos do Projeto
1. O website deve ser desenvolvido com o framework React.
2. O website deve apresentar dados detalhados de pelo menos três entidades de negócio
relacionadas domínio do projeto. Por exemplo, para uma livraria poderiam ser consideradas
entidades como livro, editora, autor, área, pedido, cliente etc.
Sugestão: Use como base a estrutura do website de exemplo apresentado em aula, a qual
contém áreas para logotipo, menu de navegação, conteúdo principal e rodapé.
3. O website deve implementar os seguintes conceitos e recursos apresentados em aula:
• Single Page Application;
• Componentização da interface de usuário;
• JSX (JavaScript XML)
• Passagem de dados com o objeto props;
• Atualização de dados com o objeto state;
• Navegação por rotas por meio da biblioteca React Router;
• Carregamento dinâmico de todo o conteúdo do website a partir de um repositório de
imagens e de um arquivo JSON;
• Tabela com funcionalidades para criação, alteração e exclusão de registros das entidades de
negócio.
Restrições do Projeto
1. Este projeto contempla exclusivamente o desenvolvimento front-end do website. Por este
motivo não deve existir no projeto código back-end, nem integração com sistemas
gerenciadores de banco de dados.
2. O website não deve apresentar ao usuário elementos de interface que não estejam funcionais.
Critérios de Avaliação
Serão avaliados no projeto:
• Apresentação do website em laboratório de aula;
• Implementação dos conceitos e recursos apresentados na disciplina;
• Organização do código;
• Usabilidade das funcionalidades;
• Aparência geral do website.

Informações para Entrega
• Data de Entrega: 10/06/2026 (impreterivelmente até às 23:59).
• Forma de Entrega: O projeto completo deverá ser entregue exclusivamente por meio do
ambiente Moodle (http://eadcampus.spo.ifsp.edu.br). Não serão aceitos links para
repositórios externos.

contendo uma pasta com todos os arquivos do projeto. Não esqueça de excluir o diretório
node_modules do projeto. Se o arquivo compactado ficar maior que 10 MB (limite do Moodle),
reduza a resolução dos arquivos de imagem.
• O nome do arquivo compactado deverá ser composto da seguinte forma, considerando a
ordem alfabética dos nomes:
“ProjetoDWE2_” + “NomeSobrenomeAluno1_” + “NomeSobrenomeAluno2_” +
“NomeSobrenomeAluno3”.zip
Exemplo: ProjetoDWE2_JoaoSilva_MariaPereira_PedroOliveira.zip
• O grupo que não realizar a entrega no Moodle dentro do prazo ficará com nota zero no projeto,
independentemente de se prontificar para apresentá-lo na aula.
Informações para Apresentação do Projeto
• Data da apresentação: 11/06/2026
• As apresentações estão previstas para iniciarem às 19:00.
• Cada grupo deverá apresentar seu projeto no laboratório de aula, conforme o domínio de
negócio e a ordem de apresentação sorteados no dia da formação dos grupos.
• A apresentação não deve ultrapassar 15 minutos e deve contemplar a seguinte ordem:
1. Breve descrição do domínio de negócio do projeto. Obs.: O uso de PowerPoint é opcional.
2. Navegação e apresentação das funcionalidades do website.
3. Apresentação do código, destacando os conceitos e recursos solicitados nos requisitos do
projeto.
4. Abertura para perguntas.
• O projeto pode ser apresentado no computador instalado na mesa do professor ou em
notebook próprio de um dos integrantes do grupo. Seja como for, o grupo deve estar
preparado para apresentar o projeto mesmo que a internet do campus não esteja disponível no
momento da apresentação.
• Durante a apresentação, cada aluno deve direcionar sua fala para todo o público, e não apenas
para o professor.
• Penalidades:
o Ordem de apresentação: A ordem de apresentação dos projetos não poderá ser modificada
no dia da apresentação. Caso um grupo não apresente na sua vez, será descontado 1,0 ponto
na nota do projeto, ficando a apresentação deste grupo agendada como última na ordem de
apresentações. Obs.: O projeto de um grupo pode ser apresentado mesmo que um dos
integrantes não esteja presente, porém este será penalizado conforme mencionado a seguir.
o Ausência na apresentação: O aluno ou grupo que se ausentar na apresentação ficará com
metade da nota final do projeto, independentemente de ter realizado a entrega no Moodle.
o Atraso na apresentação: O aluno do grupo que se atrasar e não estiver presente desde o
início da apresentação, ficará com 3,0 pontos a menos na nota final do projeto.
